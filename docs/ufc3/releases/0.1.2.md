Native EA SPORTS UFC 3 port (PS4 `CUSA06534`, update 1.14) for Windows and Linux.
**No game files are included**: you need your own dump of the game and its 1.14 update.

### Fixed
- **Octagon floor noise and gray blocks.** The spot-light shadow map is a 6-layer depth array
  that the game reads layer by layer as raw 16-bit values to build its shadow min/max map; only
  the first layer was converted, so five of the six lights produced garbage shadows on the
  canvas. Every layer is converted now.

### Downloads
- **Windows**: `UFC3Native-ufc3-v0.1.2-windows-x86_64.zip` — extract (not inside a OneDrive
  folder), run `UFC3.exe`, pick the `CUSA06534` folder, press **Play**.
- **Linux**: `UFC3Native-ufc3-v0.1.2-linux-x86_64.tar.gz` — glibc 2.38+ and `python3`;
  `./ufc3.sh /path/to/PS4/CUSA06534`.

### Known issues
- Untested on AMD GPUs. No online play yet (EA's servers closed in February 2025).

Problems: attach the newest log (`%LOCALAPPDATA%\UFC3Native\logs` on Windows,
`~/.local/share/UFC3Native/logs` on Linux).
