First release of the native EA SPORTS UFC 3 port (PS4 `CUSA06534`, update 1.14) for Windows.
Linux: build from source (`bash build.sh && bash run.sh`, see the README).

**No game files are included** — you need your own dump of the game and its 1.14 update.

### Download
`UFC3Native-ufc3-v0.1.0-windows-x86_64.zip` — extract, run `UFC3.exe`, pick the `CUSA06534`
folder (the `-patch` folder next to it is merged automatically), press **Play**.
The `.sha256` file has the archive's checksum.

### What's in it
- Playable: menus, fights, sound, controller, saves, local 2-player.
- Performance (RTX 4070 / Ryzen 5 5600, Linux): menus 240 FPS (the game's cap), fights
  137–196 FPS uncapped. On an RTX 3060 Laptop (Windows) menus run at 240 FPS; fights were
  66–83 FPS before this release's write-window change and still need to be measured with it.
- Launcher (God of War III port style): game and display resolution (1080p / 1440p / 4K with
  AMD FSR 1.0 + RCAS), FPS limit up to unlimited, present mode, fullscreen, player name, and a
  **Controls** editor for keyboard and gamepad.
- Separate update folders merged automatically (hard links).

### Known issues
- Noise / gray blocks on the octagon floor.
- The first-run tutorial videos cannot be skipped.
- Untested on AMD GPUs.
- Online play is not available (EA's servers closed in February 2025). For two players at a
  distance: local 2-player with Steam Remote Play Together or Parsec.

Problems: attach the newest log from `%LOCALAPPDATA%\UFC3Native\logs`.
