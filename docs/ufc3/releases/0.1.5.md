Native EA SPORTS UFC 3 port (PS4 `CUSA06534`, update 1.14) for Windows and Linux.
**No game files are included**: you need your own dump of the game and its 1.14 update.

Write windows are back on Windows, blood and sweat are back, two new launchers, and online
rematches work. How to play online: [HOW-TO-PLAY-ONLINE.md](../HOW-TO-PLAY-ONLINE.md).

### Performance

- **Write windows on by default on Windows again** (and single-stepped writes on Windows and
  Linux). UFC-48 made them coherent, which fixes the 0.1.4 heap corruption that forced them off.
  On an RTX 3060 laptop a Career fight goes from about 30 to 60–70 FPS.
- Logs written to a network drive with frame statistics on no longer stall the GPU thread
  (`readbacks.csv` is flushed once a second instead of on every readback).

### Graphics

- **Blood and sweat on hits are back** (missing since 0.1.3; `BB_PREUPLOAD=1` again), with the
  created fighter's skin still correct.

### Crash and freeze fixes

- Fixed a GPU hang (device lost) when changing hair/head repeatedly in the Career fighter editor.
- Possible fix for AMD freezes and closes (late EOS labels were being dropped). **AMD users:
  please report** whether this helps.
- Validated on Windows: second fight and career contract without a crash.

### Launchers

- **Windows:** new UFC 3 dark/gold look (your dump's own artwork in the banner), a log folder
  setting, and Offline / Join server / Host server for online play.
- **Linux:** new GTK launcher with the same Offline / Join / Host modes
  (`python3 launcher/ufc3_launcher.py`, or `./ufc3.sh` with no arguments).

### Online

- Rematch now works.
- Play outside your LAN with a VPN such as Tailscale: see
  [HOW-TO-PLAY-ONLINE.md](../HOW-TO-PLAY-ONLINE.md).

### Experimental

- 2K (2560x1440) and 4K (3840x2160) internal resolution in the launcher's resolution list.
  In game, choose VIDEO → RESOLUTION → *Favor Resolution* (the option only appears in these
  modes). Validated on Linux only.

### Known issues

- Fights on Windows still run below Linux.
- Keep the log folder on a local disk for the best FPS.
- "Clear shader cache" recompiles every shader on each start: leave it off.
