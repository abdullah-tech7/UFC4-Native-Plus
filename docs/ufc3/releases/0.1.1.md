Native EA SPORTS UFC 3 port (PS4 `CUSA06534`, update 1.14) — now with a **Linux** build.
**No game files are included**: you need your own dump of the game and its 1.14 update.

### Downloads
- **Windows**: `UFC3Native-ufc3-v0.1.1-windows-x86_64.zip` — extract (not inside a OneDrive
  folder), run `UFC3.exe`, pick the `CUSA06534` folder, press **Play**.
- **Linux**: `UFC3Native-ufc3-v0.1.1-linux-x86_64.tar.gz` — glibc 2.38+ (Ubuntu 24.04+,
  Debian 13+, Fedora 39+, Arch, SteamOS) and `python3`; SDL3 and the other libraries are
  bundled. `tar xf ... && cd UFC3Native && ./ufc3.sh /path/to/PS4/CUSA06534`. Settings in
  `~/.local/share/UFC3Native/ufc3.conf`, controls in `bbport.ini` there (see README-Linux.md).
- `.sha256` files: checksums.

### Changes since 0.1.0
- **Intro videos skipped** by default: the EA logo and the 2.5-minute first-start video play a
  short black clip instead (launcher: "Skip the intro videos"; Linux: `BB_SKIP_MOVIES=0` in
  `ufc3.conf` to watch them).
- Linux release archive (portable build: bundled SDL3/libstdc++, relative library paths).
- Windows launcher: when a program in `bin\` cannot start (e.g. error 0xC0000022, access
  denied — usually an antivirus, a OneDrive-synced folder or a blocked zip), the log explains
  it instead of a system error box.
- No build-machine paths in the binaries' log messages.

### Known issues
- Noise / gray blocks on the octagon floor. Untested on AMD GPUs. No online play (EA's servers
  closed in February 2025).

Problems: attach the newest log (`%LOCALAPPDATA%\UFC3Native\logs` on Windows,
`~/.local/share/UFC3Native/logs` on Linux).
