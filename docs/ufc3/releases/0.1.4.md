Native EA SPORTS UFC 3 port (PS4 `CUSA06534`, update 1.14) for Windows and Linux.
**No game files are included**: you need your own dump of the game and its 1.14 update.

Hotfix release on top of 0.1.3. It turns write windows off by default on Windows and
preserves the portrait captures the game re-reads at a different size. Nothing else
changes; see [the 0.1.3 notes](0.1.3.md) for the rest of the feature set.

### Fixes

- **Windows crash after creating a career fighter, signing the contract or loading the
  second fight.** Write windows corrupted the game's heap on Windows: the guest heap's
  free list ended up damaged and the game crashed, usually while the second fight loaded
  or the career contract was signed. We collected five cases (RX 9070, RTX 4090, RTX 3060
  and RX 7800 XT twice), and they happened even with `BB_WRITE_STEP=0`. The Windows
  launcher now defaults to `BB_WRITE_WINDOW=0`; with it off, the RX 7800 XT user who
  reported the crash has not crashed again. The cost is lower in-fight FPS on Windows.
  Set `BB_WRITE_WINDOW=1` before starting the launcher (for example from a `.bat`) to
  re-enable write windows, at the risk of those crashes; a `BB_WRITE_WINDOW` value
  already in the environment always wins over the launcher default. Linux has no such
  reports and keeps write windows on (`run.sh` still sets `BB_WRITE_WINDOW=1`).

- **Career portraits and post-fight screen.** Your fighter now appears on the post-fight
  menu, the portrait shows up in the career pause menu, and Saved Careers cards no longer
  show static over the flag. Cause: the game draws the portrait into a larger render
  target (for example 1024x2048) and then reads it back at the portrait's size
  (864x1360, 652x1080, 600x1080, 1000x1200, 360x260, 252x400…) in the same memory. The
  texture cache discarded that content and reloaded old memory instead. It now preserves
  it with a copy that stays on the GPU; the first single-mip read and the small sizes are
  covered too. `BB_T4_PRESERVE_ALIAS=0` disables the preservation.
  Details: [`UFC-13-FIX-ALIAS.md`](../UFC-13-FIX-ALIAS.md) and
  [`UFC-13-QUINTA-PASADA.md`](../UFC-13-QUINTA-PASADA.md).

### Known issues

- **Write windows on Windows:** the heap corruption is now avoided by keeping them off by
  default, so this is a performance limitation rather than a crash. The underlying cause
  remains under investigation; re-enabling with `BB_WRITE_WINDOW=1` brings the crash risk
  back. Linux keeps them on.
- **Long hairstyles:** some leave a slightly lighter line at the base of the neck.
- **Portuguese (Portugal), `BB_LANGUAGE=7`:** the game has no text for this language,
  even though the launcher lists it. Select Portuguese (Brazil), `BB_LANGUAGE=17`.
- No online play yet; this release does not change the online implementation.

### Downloads

- **Windows**: `UFC3Native-ufc3-v0.1.4-windows-x86_64.zip` — extract (not inside a
  OneDrive folder), run `UFC3.exe`, pick the `CUSA06534` folder, press **Play**.
- **Linux**: `UFC3Native-ufc3-v0.1.4-linux-x86_64.tar.gz` — glibc 2.38+ and `python3`;
  `./ufc3.sh /path/to/PS4/CUSA06534`.

Problems: attach the newest log (`%LOCALAPPDATA%\UFC3Native\logs` on Windows,
`~/.local/share/UFC3Native/logs` on Linux).
